# iOS 설치형 PWA 상단 흐림 우회

사용자 환경: iOS 27.0, 홈 화면에 설치한 PWA. 상태바 아래 헤더의 로고·그룹 이름·버튼 윗부분까지 흐려지는 스크린샷을 확인했다.

## 적용

- `index.html`에 React 루트 밖의 빈 요소를 하나 둔다.
- 홈 화면 앱 모드이고 `-webkit-touch-callout`과 텍스트 배경 클리핑을 지원할 때만 켠다. iOS 버전 판별은 아니므로 해당 기능을 지원하는 이전 버전에도 적용된다.
- 높이 11px, 가로 전체 폭의 고정 요소에 기존 `--status-bar` 색을 지정한다. WebKit의 상단 배경 판정에 사용하는 비공식 우회다.
- 빈 텍스트로 배경을 클리핑해 화면에 띠를 그리지 않는다. 문서 흐름 밖에 있어 콘텐츠 높이·여백을 늘리지 않고 터치도 가로채지 않는다.
- 기존 상태바 배경, safe-area 여백, viewport 및 meta 설정은 유지한다.
- 모바일 화면 전체의 세로 스크롤바만 숨긴다. 문서 스크롤과 목록 내부 스크롤바는 유지한다.

## iOS 27.0 실기기 확인 (미실행)

1. 배포된 새 버전을 받은 뒤 설치형 PWA를 완전히 닫았다 다시 연다. 사이트 데이터 삭제나 재설치는 하지 않는다.
2. 이전 스크린샷과 같은 화면·테마에서 로고, 그룹 이름, 계정 버튼의 선명도를 비교한다.
3. 스크롤 전후, 화면 전환, 밝은/어두운 테마, 가로/세로 회전, 키보드 열고 닫기를 확인한다.
4. 상단 버튼과 시트가 정상 동작하고, 새 띠·상단 여백·콘텐츠 높이 변화가 없는지 확인한다.
5. 일반 Safari 탭에서는 기존과 같은지 비교한다. 실제 기기·OS 세부 버전·배포 커밋과 전후 결과를 기록한다.
