## 캡처 기준

- 다이어그램은 본문에 정적 미리보기와 설명을 함께 두고, 큰 상호작용 보기는 별도 링크한다. 작은 화면에서는 그림 안에서만 가로 스크롤하며 페이지 전체가 넘치지 않게 한다.
- 운영 대시보드는 현재 UI에서 확인한 화면만 사용한다. Secret·토큰·쿠키·계정 개인정보가 있는 설정 화면 대신 실행 상태·단계·커밋 등 필요한 영역만 캡처한다.
- 캡처에는 확인일·환경(개발/검증/운영)을 붙인다. 일시적 장애 화면을 정상 상태의 예시로 쓰지 않는다.
- 저장소의 기존 소분류 대시보드 스크린샷은 현재 4개 가이드의 설정 절차를 보여주지 않으므로 장식용으로 추가하지 않는다.
- 이번 작업에서는 실제 앱이나 운영 플랫폼을 새로 기동·조작하지 않았다. Archify 렌더링을 캡처했으며 실제 운영 환경 이미지로 표시하지 않는다.

## 이번 반영

`docs/site/pr38-update.html`의 기존 URL을 유지하면서 공통 가이드 스타일의 버전 관리 문서로 교체했다.
두 흐름도는 현재 소스 근거를 붙여 Archify finalize의 validate·deliver·check·browser-check를 통과했다.
출력 HTML은 `docs/site/diagrams/`, 본문 이미지는 `docs/site/images/`에 둔다.
기준 JSON은 `docs/diagram-sources/`에서 관리하고, 생성·검증 기록은 게시하지 않는다.
