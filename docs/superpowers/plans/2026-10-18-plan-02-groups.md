# Plan 02 — 그룹·초대·공개 설정 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 회원이 그룹을 만들고(생성자 = ADMIN), 초대 URL 토큰으로 다른 회원을 최대 6명까지 합류시키고, 멤버를 추방하거나 탈퇴하고, 그룹별로 내 데이터 공개 여부를 정할 수 있는 API를 만든다. Plan 03이 쓸 권한 조회(`GroupAccess`)도 함께 만든다.

**Architecture:** 새 기능 패키지 `com.saladbowl.api.group` 하나에 엔티티, 리포지토리, 서비스, 컨트롤러를 둔다. 엔티티끼리는 연관관계 매핑 없이 FK id 값(`groupId`, `userId`)만 가진다(`open-in-view: false`에서 지연 로딩 문제를 피한다). 권한 검사는 `GroupAccess` 한 곳에 모은다. 6명 정원은 그룹 행 비관적 락(`PESSIMISTIC_WRITE`)과 `(group_id, user_id)` unique 제약으로 지킨다.

**Tech Stack:** Java 21, Spring Boot 4.1.1, Spring Data JPA(Hibernate 7), Flyway, PostgreSQL 16, JUnit 5, MockMvc, Testcontainers 2

**선행 조건:** Plan 01(PR hyun0721/salad-bowl#1)이 `main`에 머지된 뒤 `main`에서 브랜치를 딴다. 머지 전에 시작하면 `feat/plan-01-foundation-auth`에서 브랜치를 딴다.

## 설계 결정 (스펙 보완)

스펙이 정하지 않은 부분을 이렇게 정한다. 스펙 문서 4장도 함께 갱신한다.

| 항목 | 결정 |
|---|---|
| GroupShare | 별도 테이블 대신 `group_members.share_enabled` 컬럼으로 둔다. 공개 여부는 (그룹, 회원)마다 하나라서 멤버십과 수명이 같다. 탈퇴하면 함께 사라진다. |
| 공개 기본값 | 그룹을 만들거나 합류하면 `share_enabled = true`다(서비스 목적이 공유다). |
| 초대 토큰 | 32바이트 난수를 base64url(패딩 없음, 43자)로 인코딩한다. **만료(7일) 전까지 여러 명이 쓸 수 있다.** 정원이 차면 수락이 거부된다. 회수 기능은 범위 밖이다. |
| 비멤버 접근 | 그룹이 존재하더라도 비멤버에게는 `404 NOT_FOUND`를 돌려준다(그룹 존재 여부를 숨긴다). 멤버이지만 ADMIN이 아니면 `403 FORBIDDEN`이다. |
| 관리자 탈퇴 | ADMIN은 탈퇴할 수 없고(`409 ADMIN_CANNOT_LEAVE`), 추방될 수도 없다(`409 CANNOT_REMOVE_ADMIN`). 관리자 위임과 그룹 삭제는 범위 밖이다. |
| 추방 후 재합류 (최종 리뷰 반영) | 추방된 회원은 `group_bans`에 기록되고, 어떤 초대 토큰으로도 미리보기·수락할 수 없다(`403 REMOVED_FROM_GROUP`). 다른 초대는 그대로 유효하다. ADMIN은 차단 목록을 보고 해제할 수 있다. 스스로 탈퇴한 회원은 차단되지 않는다. |
| 테이블 이름 | `groups`는 SQL 키워드와 겹치므로 `user_groups`로 하고, 엔티티 이름도 `UserGroup`으로 한다(JPQL의 `GROUP` 예약어 회피). |

```java
    @ExceptionHandler(Exception.class)
    public ResponseEntity<ErrorResponse> handleUnexpected(Exception e) {
        // Spring 예외 중 상당수(MissingServletRequestParameterException, ResponseStatusException 등)는
        // org.springframework.web.ErrorResponse를 구현하고 자기 status를 가진다. 이를 500으로 덮지 않는다.
        if (e instanceof org.springframework.web.ErrorResponse framework) {
            return frameworkError(framework, e);
        }
        log.error("Unhandled exception", e);
        return error(ErrorCode.INTERNAL_ERROR, "internal server error");
    }

    private static ResponseEntity<ErrorResponse> frameworkError(org.springframework.web.ErrorResponse framework,
                                                                Exception e) {
        HttpStatusCode status = framework.getStatusCode();
        if (status.is5xxServerError()) {
            log.error("Framework server error", e);
        }
        String code = switch (status.value()) {
            case 400 -> ErrorCode.VALIDATION_FAILED.name();
            case 401 -> ErrorCode.UNAUTHORIZED.name();
            case 403 -> ErrorCode.FORBIDDEN.name();
            case 404 -> ErrorCode.NOT_FOUND.name();
            case 405 -> ErrorCode.METHOD_NOT_ALLOWED.name();
            case 409 -> ErrorCode.CONFLICT.name();
            case 415 -> ErrorCode.UNSUPPORTED_MEDIA_TYPE.name();
            default -> status.is5xxServerError() ? ErrorCode.INTERNAL_ERROR.name() : ErrorCode.REQUEST_FAILED.name();
        };
        String detail = framework.getBody().getDetail();
        String message = status.is5xxServerError() || detail == null ? "request failed" : detail;
        return ResponseEntity.status(status).body(new ErrorResponse(code, message));
    }
```

```java
import com.jayway.jsonpath.JsonPath;
import org.springframework.http.MediaType;
import org.springframework.test.web.servlet.MockMvc;

import static org.springframework.test.web.servlet.request.MockMvcRequestBuilders.post;
import static org.springframework.test.web.servlet.result.MockMvcResultMatchers.status;

/** 통합 테스트용: 회원가입 후 로그인해서 id와 access 토큰을 돌려준다. */
public final class TestAuth {

    public static final String PASSWORD = "password123";

    public record AuthedUser(long id, String email, String token) {

        public String bearer() {
            return "Bearer " + token;
        }
    }

    private TestAuth() {
    }

    public static AuthedUser signupAndLogin(MockMvc mvc, String email, String nickname) throws Exception {
        String signupBody = mvc.perform(post("/auth/signup").contentType(MediaType.APPLICATION_JSON)
                        .content("""
                                {"email":"%s","password":"%s","nickname":"%s"}
                                """.formatted(email, PASSWORD, nickname)))
                .andExpect(status().isCreated())
                .andReturn().getResponse().getContentAsString();

        String loginBody = mvc.perform(post("/auth/login").contentType(MediaType.APPLICATION_JSON)
                        .content("""
                                {"email":"%s","password":"%s"}
                                """.formatted(email, PASSWORD)))
                .andExpect(status().isOk())
                .andReturn().getResponse().getContentAsString();
        String token = JsonPath.read(loginBody, "$.accessToken");
        return new AuthedUser(id, email, token);
    }
}
```

```java
package com.saladbowl.api.group;

import com.saladbowl.api.support.IntegrationTest;
import com.saladbowl.api.user.User;
import com.saladbowl.api.user.UserRepository;
import org.junit.jupiter.api.Test;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.dao.DataIntegrityViolationException;

import java.time.OffsetDateTime;
import java.util.List;

import static org.assertj.core.api.Assertions.assertThat;
import static org.assertj.core.api.Assertions.assertThatThrownBy;

class GroupRepositoryTest extends IntegrationTest {

    @Autowired
    UserRepository users;

    @Autowired
    UserGroupRepository groups;

    @Autowired
    GroupMemberRepository members;

    @Autowired
    GroupInviteRepository invites;

    private User user(String email, String nickname) {
        return users.save(new User(email, "hash", nickname));
    }

    @Test
    void memberRowsJoinNicknamesInJoinOrder() {
        User admin = user("admin@test.com", "관리자");
        User member = user("member@test.com", "멤버");
        UserGroup group = groups.save(new UserGroup("우리집", admin.getId()));
        members.save(new GroupMember(group.getId(), admin.getId(), GroupRole.ADMIN));
        members.save(new GroupMember(group.getId(), member.getId(), GroupRole.MEMBER));

        List<MemberRow> rows = members.findMemberRows(group.getId());

        assertThat(rows).extracting(MemberRow::nickname).containsExactly("관리자", "멤버");
        assertThat(rows).extracting(MemberRow::role).containsExactly(GroupRole.ADMIN, GroupRole.MEMBER);
        assertThat(rows).allMatch(MemberRow::shareEnabled);
        assertThat(members.countByGroupId(group.getId())).isEqualTo(2);
    }

    @Test
    void sameUserCannotJoinSameGroupTwice() {
        User admin = user("admin2@test.com", "관리자");
        UserGroup group = groups.save(new UserGroup("우리집", admin.getId()));
        members.saveAndFlush(new GroupMember(group.getId(), admin.getId(), GroupRole.ADMIN));

        assertThatThrownBy(() -> members.saveAndFlush(
                new GroupMember(group.getId(), admin.getId(), GroupRole.MEMBER)))
                .isInstanceOf(DataIntegrityViolationException.class);
    }

    @Test
    void inviteIsFoundByTokenAndKnowsExpiry() {
        User admin = user("admin3@test.com", "관리자");
        UserGroup group = groups.save(new UserGroup("우리집", admin.getId()));
        OffsetDateTime expiresAt = OffsetDateTime.now().plusDays(7);
        invites.save(new GroupInvite(group.getId(), "token-abc", admin.getId(), expiresAt));

        GroupInvite found = invites.findByToken("token-abc").orElseThrow();

        assertThat(found.getGroupId()).isEqualTo(group.getId());
        assertThat(found.isExpiredAt(OffsetDateTime.now())).isFalse();
        assertThat(found.isExpiredAt(expiresAt.plusSeconds(1))).isTrue();
    }
}
```

```java
package com.saladbowl.api.group;

import com.saladbowl.api.common.ApiException;
import com.saladbowl.api.common.ErrorCode;
import com.saladbowl.api.group.GroupDtos.GroupDetail;
import com.saladbowl.api.group.GroupDtos.GroupSummary;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.util.List;

@Service
public class GroupService {

    private final UserGroupRepository groups;
    private final GroupMemberRepository members;
    private final GroupAccess access;

    public GroupService(UserGroupRepository groups, GroupMemberRepository members, GroupAccess access) {
        this.groups = groups;
        this.members = members;
        this.access = access;
    }

    @Transactional
    public GroupSummary create(long userId, String name) {
        UserGroup group = groups.save(new UserGroup(name.trim(), userId));
        members.save(new GroupMember(group.getId(), userId, GroupRole.ADMIN));
        return new GroupSummary(group.getId(), group.getName(), GroupRole.ADMIN, 1);
    }

    @Transactional(readOnly = true)
    public List<GroupSummary> listMine(long userId) {
        return members.findByUserIdOrderByJoinedAtAsc(userId).stream()
                .map(membership -> {
                    UserGroup group = findGroup(membership.getGroupId());
                    return new GroupSummary(group.getId(), group.getName(), membership.getRole(),
                            members.countByGroupId(group.getId()));
                })
                .toList();
    }

    @Transactional(readOnly = true)
    public GroupDetail detail(long groupId, long userId) {
        GroupMember me = access.requireMember(groupId, userId);
        UserGroup group = findGroup(groupId);
        return new GroupDetail(group.getId(), group.getName(), me.getRole(), members.findMemberRows(groupId));
    }

    @Transactional
    public GroupDetail rename(long groupId, long userId, String name) {
        access.requireAdmin(groupId, userId);
        findGroup(groupId).rename(name.trim());
        return detail(groupId, userId);
    }

    private UserGroup findGroup(long groupId) {
        return groups.findById(groupId)
                .orElseThrow(() -> new ApiException(ErrorCode.NOT_FOUND, "group not found"));
    }
}
```

```java
package com.saladbowl.api.group;

import com.saladbowl.api.common.ApiException;
import com.saladbowl.api.common.ErrorCode;
import com.saladbowl.api.group.InviteDtos.AcceptResponse;
import com.saladbowl.api.group.InviteDtos.InvitePreview;
import com.saladbowl.api.group.InviteDtos.InviteResponse;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.security.SecureRandom;
import java.time.Duration;
import java.time.OffsetDateTime;
import java.util.Base64;

@Service
public class InviteService {

    static final int MAX_MEMBERS = 6;
    static final Duration INVITE_TTL = Duration.ofDays(7);

    private static final SecureRandom RANDOM = new SecureRandom();

    private final UserGroupRepository groups;
    private final GroupMemberRepository members;
    private final GroupInviteRepository invites;
    private final GroupAccess access;

    public InviteService(UserGroupRepository groups, GroupMemberRepository members,
                         GroupInviteRepository invites, GroupAccess access) {
        this.groups = groups;
        this.members = members;
        this.invites = invites;
        this.access = access;
    }

    @Transactional
    public InviteResponse issue(long groupId, long userId) {
        access.requireAdmin(groupId, userId);
        GroupInvite invite = invites.save(
                new GroupInvite(groupId, newToken(), userId, OffsetDateTime.now().plus(INVITE_TTL)));
        return new InviteResponse(invite.getToken(), invite.getExpiresAt());
    }

    @Transactional(readOnly = true)
    public InvitePreview preview(String token, long userId) {
        GroupInvite invite = validInvite(token);
        UserGroup group = groups.findById(invite.getGroupId()).orElseThrow(InviteService::inviteNotFound);
        return new InvitePreview(group.getName(), members.countByGroupId(group.getId()), MAX_MEMBERS,
                invite.getExpiresAt(), members.existsByGroupIdAndUserId(group.getId(), userId));
    }

    @Transactional
    public AcceptResponse accept(String token, long userId) {
        GroupInvite invite = validInvite(token);
        // 그룹 행을 잠가 같은 그룹에 대한 동시 수락이 정원 검사를 동시에 통과하지 못하게 한다.
        UserGroup group = groups.findByIdForUpdate(invite.getGroupId()).orElseThrow(InviteService::inviteNotFound);
        if (members.existsByGroupIdAndUserId(group.getId(), userId)) {
            throw new ApiException(ErrorCode.ALREADY_MEMBER, "already a member of this group");
        }
        if (members.countByGroupId(group.getId()) >= MAX_MEMBERS) {
            throw new ApiException(ErrorCode.GROUP_FULL, "group is full");
        }
        members.save(new GroupMember(group.getId(), userId, GroupRole.MEMBER));
        return new AcceptResponse(group.getId());
    }

    private GroupInvite validInvite(String token) {
        GroupInvite invite = invites.findByToken(token).orElseThrow(InviteService::inviteNotFound);
        if (invite.isExpiredAt(OffsetDateTime.now())) {
            throw new ApiException(ErrorCode.INVITE_EXPIRED, "invite expired");
        }
        return invite;
    }

    private static ApiException inviteNotFound() {
        return new ApiException(ErrorCode.INVITE_NOT_FOUND, "invite not found");
    }

    private static String newToken() {
        byte[] bytes = new byte[32];
        RANDOM.nextBytes(bytes);
        return Base64.getUrlEncoder().withoutPadding().encodeToString(bytes);
    }
}
```

```java
package com.saladbowl.api.group;

import com.saladbowl.api.auth.CurrentUser;
import com.saladbowl.api.group.InviteDtos.AcceptResponse;
import com.saladbowl.api.group.InviteDtos.InvitePreview;
import com.saladbowl.api.group.InviteDtos.InviteResponse;
import org.springframework.http.HttpStatus;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.PathVariable;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class InviteController {

    private final InviteService inviteService;

    public InviteController(InviteService inviteService) {
        this.inviteService = inviteService;
    }

    @PostMapping("/groups/{groupId}/invites")
    public ResponseEntity<InviteResponse> issue(@CurrentUser Long userId, @PathVariable long groupId) {
        return ResponseEntity.status(HttpStatus.CREATED).body(inviteService.issue(groupId, userId));
    }

    @GetMapping("/invites/{token}")
    public InvitePreview preview(@CurrentUser Long userId, @PathVariable String token) {
        return inviteService.preview(token, userId);
    }

    @PostMapping("/invites/{token}/accept")
    public AcceptResponse accept(@CurrentUser Long userId, @PathVariable String token) {
        return inviteService.accept(token, userId);
    }
}
```

```java
package com.saladbowl.api.group;

import com.saladbowl.api.support.IntegrationTest;
import com.saladbowl.api.support.TestAuth;
import com.saladbowl.api.support.TestAuth.AuthedUser;
import com.saladbowl.api.support.TestGroups;
import org.junit.jupiter.api.Test;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.http.MediaType;
import org.springframework.test.web.servlet.MockMvc;

import static org.springframework.test.web.servlet.request.MockMvcRequestBuilders.get;
import static org.springframework.test.web.servlet.request.MockMvcRequestBuilders.put;
import static org.springframework.test.web.servlet.result.MockMvcResultMatchers.jsonPath;
import static org.springframework.test.web.servlet.result.MockMvcResultMatchers.status;

class ShareApiTest extends IntegrationTest {

    @Autowired
    MockMvc mvc;

    @Test
    void memberTurnsSharingOffAndOn() throws Exception {
        AuthedUser admin = TestAuth.signupAndLogin(mvc, "admin@test.com", "관리자");
        AuthedUser member = TestAuth.signupAndLogin(mvc, "member@test.com", "멤버");
        long groupId = TestGroups.createGroup(mvc, admin, "우리집");
        TestGroups.join(mvc, admin, member, groupId);

        mvc.perform(put("/groups/" + groupId + "/share").header("Authorization", member.bearer())
                        .contentType(MediaType.APPLICATION_JSON)
                        .content("""
                                {"enabled":false}
                                """))
                .andExpect(status().isOk())
                .andExpect(jsonPath("$.shareEnabled").value(false));

        mvc.perform(get("/groups/" + groupId).header("Authorization", admin.bearer()))
                .andExpect(jsonPath("$.members[1].userId").value(member.id()))
                .andExpect(jsonPath("$.members[1].shareEnabled").value(false));

        mvc.perform(put("/groups/" + groupId + "/share").header("Authorization", member.bearer())
                        .contentType(MediaType.APPLICATION_JSON)
                        .content("""
                                {"enabled":true}
                                """))
                .andExpect(jsonPath("$.shareEnabled").value(true));
    }

    @Test
    void missingEnabledReturns400() throws Exception {
        AuthedUser admin = TestAuth.signupAndLogin(mvc, "admin@test.com", "관리자");
        long groupId = TestGroups.createGroup(mvc, admin, "우리집");

        mvc.perform(put("/groups/" + groupId + "/share").header("Authorization", admin.bearer())
                        .contentType(MediaType.APPLICATION_JSON)
                        .content("{}"))
                .andExpect(status().isBadRequest())
                .andExpect(jsonPath("$.code").value("VALIDATION_FAILED"));
    }

    @Test
    void outsiderGets404() throws Exception {
        AuthedUser admin = TestAuth.signupAndLogin(mvc, "admin@test.com", "관리자");
        AuthedUser outsider = TestAuth.signupAndLogin(mvc, "out@test.com", "외부인");
        long groupId = TestGroups.createGroup(mvc, admin, "우리집");

        mvc.perform(put("/groups/" + groupId + "/share").header("Authorization", outsider.bearer())
                        .contentType(MediaType.APPLICATION_JSON)
                        .content("""
                                {"enabled":false}
                                """))
                .andExpect(status().isNotFound());
    }
```

```java
package com.saladbowl.api.group;

import com.saladbowl.api.support.IntegrationTest;
import com.saladbowl.api.support.TestAuth;
import com.saladbowl.api.support.TestAuth.AuthedUser;
import com.saladbowl.api.support.TestGroups;
import org.junit.jupiter.api.BeforeEach;
import org.junit.jupiter.api.Test;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.http.MediaType;
import org.springframework.test.web.servlet.MockMvc;

import static org.assertj.core.api.Assertions.assertThat;
import static org.springframework.test.web.servlet.request.MockMvcRequestBuilders.put;
import static org.springframework.test.web.servlet.result.MockMvcResultMatchers.status;

class GroupAccessTest extends IntegrationTest {

    @Autowired
    MockMvc mvc;

    @Autowired
    GroupAccess access;

    AuthedUser admin;
    AuthedUser sharing;
    AuthedUser hiding;
    long groupId;

    @BeforeEach
    void setUp() throws Exception {
        admin = TestAuth.signupAndLogin(mvc, "admin@test.com", "관리자");
        sharing = TestAuth.signupAndLogin(mvc, "sharing@test.com", "공개");
        hiding = TestAuth.signupAndLogin(mvc, "hiding@test.com", "비공개");
        groupId = TestGroups.createGroup(mvc, admin, "우리집");
        TestGroups.join(mvc, admin, sharing, groupId);
        TestGroups.join(mvc, admin, hiding, groupId);
        mvc.perform(put("/groups/" + groupId + "/share").header("Authorization", hiding.bearer())
                        .contentType(MediaType.APPLICATION_JSON)
                        .content("""
                                {"enabled":false}
                                """))
                .andExpect(status().isOk());
    }

    @Test
    void sharedOwnerIdsExcludesMembersWhoTurnedSharingOff() {
        assertThat(access.sharedOwnerIds(groupId)).containsExactly(admin.id(), sharing.id());
    }

    @Test
    void ownerCanAlwaysEditOwnData() {
        assertThat(access.canEditOwnedBy(hiding.id(), hiding.id())).isTrue();
    }

    @Test
    void adminCanEditDataOfMemberWhoSharesWithTheGroup() {
        assertThat(access.canEditOwnedBy(admin.id(), sharing.id())).isTrue();
    }

    @Test
    void adminCannotEditDataOfMemberWhoTurnedSharingOff() {
        assertThat(access.canEditOwnedBy(admin.id(), hiding.id())).isFalse();
    }

    @Test
    void memberCannotEditAdminData() {
        assertThat(access.canEditOwnedBy(sharing.id(), admin.id())).isFalse();
    }

    @Test
    void adminOfAnotherGroupCannotEdit() throws Exception {
        AuthedUser otherAdmin = TestAuth.signupAndLogin(mvc, "other@test.com", "다른관리자");
        TestGroups.createGroup(mvc, otherAdmin, "다른집");

        assertThat(access.canEditOwnedBy(otherAdmin.id(), sharing.id())).isFalse();
    }
}
```
