# Plan 13 후속

## 브라우저 확인 (Playwright + 시스템 Chrome, 임시 미리보기)
- 모바일(iPhone 13) 밝은·어두운 테마에서 단계 1~4 화면, 데스크톱 덮개와 완료 모션(남은 재료 담기 → 닫힘)을 확인했다.
- 카드 안 보조 문구가 한 글자만 넘어가는 줄바꿈을 `word-break: keep-all` + `text-wrap: balance`로 고쳤다.

## 실기기·눈으로 확인 (사용자가 직접)
- 실제 콜드스타트에서의 느낌(단계 시점 8·30·90초가 적당한지)
- 움직임 줄이기 설정을 켠 기기
- 스크린리더(VoiceOver)로 덮개가 열릴 때 첫 멘트를 읽는지

## 나중에 (사소함, 리뷰에서 넘긴 것)
- 덮개가 닫히는 중 다시 켜지면 `extra`가 남아 볼은 가득한데 멘트는 앞 단계일 수 있다. 단계 타이머도 0초부터 다시 센다.
- `role="status"`가 내용과 함께 마운트되어 스크린리더가 첫 멘트를 놓칠 수 있다. Dialog에 `aria-describedby`를 거는 방안.
- 로그인 화면에서 느린 로그인이 성공하면 바로 다른 화면으로 넘어가 완료 모션 없이 덮개가 사라진다.
- 테스트 보강: 닫히는 중 다시 켜지는 경로, `PublicOnly` loading(로더 보임·덮개 없음).
- 빌드의 `advancedChunks` deprecated 경고(main의 vite 설정, 이번 변경과 무관).
