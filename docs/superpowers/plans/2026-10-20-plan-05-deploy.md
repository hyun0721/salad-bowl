# Plan 05 — 배포 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. 이 저장소에서는 `.claude/skills/codex-collab` 규칙으로 Task마다 구현자(Claude/Codex)를 정한다.

**Goal:** Salad Bowl을 무료 티어(Cloudflare Pages + Render + Supabase)에 배포할 수 있게 만든다. 배포를 막는 문제(엑셀 파싱 메모리, 운영 설정)를 고치고, 컨테이너·배포 설정·점검 스크립트·배포 절차서를 갖춘 뒤, 사용자와 함께 실제로 배포하고 확인한다.

**Architecture:**
- 브라우저 → Cloudflare Pages(정적 파일 + `/api/*` Function) → Render(Docker, Spring Boot) → Supabase Postgres(세션 풀러).
- 배포는 플랫폼의 Git 연동을 쓴다. `main`에 머지되면 Pages와 Render가 각자 빌드·배포한다. GitHub에는 배포용 비밀값을 두지 않는다.
- Render 서비스는 저장소의 `render.yaml`(Blueprint)로 정의하고, 비밀값은 Render 대시보드에서 넣는다.

**Tech Stack:** Spring Boot 4.1.1 / Java 21, Apache POI 5.5.1 + excel-streaming-reader 5.3.2, Docker(eclipse-temurin 21), Vite 8 / Cloudflare Pages Functions, GitHub Actions.

**선행 조건:** Plan 04c(PR hyun0721/salad-bowl#7)가 머지되어 있다. `main`에서 `feat/plan-05-deploy` 브랜치를 딴다.

**범위 밖(Plan 06 "운영·보안 보강"):** refresh 토큰 서버 측 폐기(`token_version`), 로그인 횟수 제한, 낙관적 락(`@Version`), `lock_timeout`, 무결성 오류 매핑, 초대 정리·발급 제한, 관리자 위임.

| import 트랜잭션 | 파싱을 DB 트랜잭션 밖으로 옮긴다(`TransactionTemplate`). 풀러 연결 수가 적어 파싱 중 커넥션을 잡지 않는다 |

| 설정 검증 | JWT 비밀키 32바이트 이상, `SameSite`는 `Strict`·`Lax`·`None`만, `None`이면 `Secure` 필수. 설정 레코드의 생성자에서 검사해 기동 시 실패시킨다 |
| DB 연결 | Supabase 직접 연결은 IPv6 전용이라 **세션 풀러**(IPv4, 포트 5432)를 쓴다. 사용자 이름은 `postgres.<project-ref>` 형식이다. `sslmode=require` |
| 지역 | Render와 Supabase 모두 **Singapore**. 둘을 가깝게 두어 쿼리마다 생기는 지연을 줄인다 |

| Pages 설정 | `_routes.json`으로 Function을 `/api`, `/api/*`에만 건다(정적 요청이 하루 10만 회 한도를 쓰지 않게). `_headers`로 `sw.js`·`registerSW.js`·`manifest.webmanifest`는 `no-cache`, 전체에 기본 보안 헤더 |
| 휴면 방지 | GitHub Actions가 3일마다 `<Pages 주소>/api/actuator/health`를 부른다(Render 깨우기 + DB 접근으로 Supabase 7일 휴면 방지). 주소는 저장소 변수 `API_HEALTH_URL`(비밀값 아님) |

## Global Constraints

- **새 의존성**은 `org.apache.poi:poi-ooxml:5.5.1`(5.4.1에서 올림)과 `com.github.pjfanning:excel-streaming-reader:5.3.2`만 추가한다. 웹앱은 새 패키지를 설치하지 않는다.
- **비밀값을 저장소에 넣지 않는다.** 예시는 `<...>` 자리표시로 쓰고, 실제 값은 Render·Cloudflare 대시보드에만 넣는다. 테스트용 xlsx는 코드로 만든다. 실제 뱅크샐러드 파일과 개인 데이터는 쓰지 않는다.
- **로컬 개발은 그대로 동작해야 한다.** 기본 프로필(`application.yml`)의 기본값과 `docker compose` + `bootRun` + `npm run dev` 흐름을 깨지 않는다.
- API 오류 응답은 기존 `ApiException(ErrorCode, message)` → `{code, message}` 규칙을 따른다. 예외 원인(cause)은 응답에 내보내지 않는다.
- 문서는 한국어. 문서 문체는 기존 docs처럼 "~한다"체, 화면 문구는 합니다체.
- 커밋 메시지 끝에 `Co-Authored-By: <구현 모델> <noreply@…>`(Claude: `noreply@anthropic.com`, Codex: `noreply@openai.com`).
- **구현자 배정(codex-collab):** Task 1~3은 `apps/api`·Docker라 Claude, Task 4~6은 웹 설정·스크립트·문서라 Codex. 리뷰는 구현하지 않은 쪽이 한다.

```java
package com.saladbowl.api.support;

import org.apache.poi.ss.usermodel.Cell;
import org.apache.poi.ss.usermodel.CellStyle;
import org.apache.poi.ss.usermodel.CreationHelper;
import org.apache.poi.ss.usermodel.DateUtil;
import org.apache.poi.ss.usermodel.Row;
import org.apache.poi.ss.usermodel.Sheet;
import org.apache.poi.xssf.streaming.SXSSFWorkbook;
import org.apache.poi.xssf.usermodel.XSSFWorkbook;

import java.io.IOException;
import java.io.OutputStream;
import java.nio.file.Files;
import java.nio.file.Path;
import java.time.LocalDate;

/**
 * 메모리 테스트용 큰 뱅크샐러드 형식 파일. SXSSF로 행을 디스크에 흘려 쓰므로 만드는 쪽도 메모리를 적게 쓴다.
 * 실제 export처럼 shared strings 표를 쓴다.
 */
public final class LargeBanksaladWorkbook {

    private LargeBanksaladWorkbook() {
    }

    public static void write(Path file, int rows) throws IOException {
        try (SXSSFWorkbook wb = new SXSSFWorkbook(new XSSFWorkbook(), 100, true, true);
             OutputStream out = Files.newOutputStream(file)) {
            CreationHelper helper = wb.getCreationHelper();
            CellStyle dateStyle = wb.createCellStyle();
            dateStyle.setDataFormat(helper.createDataFormat().getFormat("yyyy-mm-dd"));
            CellStyle timeStyle = wb.createCellStyle();
            timeStyle.setDataFormat(helper.createDataFormat().getFormat("hh:mm"));

            wb.createSheet("뱅샐현황").createRow(0).createCell(0).setCellValue("읽지 않는 시트");
            Sheet sheet = wb.createSheet("가계부 내역");
            Row header = sheet.createRow(0);
            for (int i = 0; i < BanksaladWorkbook.HEADERS.size(); i++) {
                header.createCell(i).setCellValue(BanksaladWorkbook.HEADERS.get(i));
            }
            double firstDay = DateUtil.getExcelDate(LocalDate.of(2026, 1, 1).atStartOfDay());
            for (int r = 1; r <= rows; r++) {
                Row row = sheet.createRow(r);
                Cell date = row.createCell(0);
                date.setCellValue(firstDay + (r % 365));
                date.setCellStyle(dateStyle);
                Cell time = row.createCell(1);
                time.setCellValue((r % 86_400) / 86_400.0);
                time.setCellStyle(timeStyle);
                row.createCell(2).setCellValue("지출");
                row.createCell(3).setCellValue("식비");
                row.createCell(4).setCellValue("카페");
                row.createCell(5).setCellValue("가맹점 " + (r % 5_000));
                row.createCell(6).setCellValue(-(1_000 + r % 50_000));
                row.createCell(7).setCellValue("KRW");
                row.createCell(8).setCellValue("카드 " + (r % 20));
                row.createCell(9).setCellValue("메모 " + (r % 1_000));
            }
            wb.write(out);
        }
    }
}
```

`apps/api/src/main/java/com/saladbowl/api/importer/BanksaladParser.java`:
- import에서 `WorkbookFactory`를 빼고 `com.github.pjfanning.xlsx.StreamingReader`, `java.util.Iterator`를 더한다.
- 클래스 Javadoc의 첫 문장을 "뱅크샐러드 export(.xlsx)의 '가계부 내역' 시트만 행 단위로 스트리밍해 읽는다. '뱅샐현황' 시트(개인정보)는 파싱하지 않는다."로 바꾼다.
- `parse`, `open`을 아래로 바꾸고 `readRows`, `invalid(String, Throwable)`를 더한다. 나머지(`checkHeader`, `parseRow`, `limited`, `occurredAt`, `date`, `seconds`, `amount`, `text`, `isBlank`)는 그대로 둔다.

```java
    public List<ParsedRow> parse(InputStream in) {
        try (Workbook workbook = open(in)) {
            Sheet sheet = workbook.getSheet(SHEET_NAME);
            if (sheet == null) {
                throw invalid("sheet '" + SHEET_NAME + "' not found");
            }
            return readRows(sheet);
        } catch (IOException e) {
            throw invalid("cannot read file", e);
        }
    }

    /** 행을 위에서부터 한 번만 지나간다. 스트리밍 시트는 임의 접근(getRow)을 지원하지 않는다. */
    private static List<ParsedRow> readRows(Sheet sheet) {
        try {
            Iterator<Row> iterator = sheet.rowIterator();
            Row header = iterator.hasNext() ? iterator.next() : null;
            if (header == null || header.getRowNum() != 0) {
                throw invalid("header row is missing");
            }
            checkHeader(header);
            List<ParsedRow> rows = new ArrayList<>();
            while (iterator.hasNext()) {
                Row row = iterator.next();
                if (!isBlank(row)) {
                    rows.add(parseRow(row));
                }
            }
            return rows;
        } catch (ApiException e) {
            throw e;
        } catch (RuntimeException e) {
            // 스트리밍 리더는 시트 XML이 깨져 있으면 읽는 도중에 던진다.
            throw invalid("cannot read sheet '" + SHEET_NAME + "'", e);
        }
    }

    /** 시트를 한 번에 메모리에 올리지 않고 100행씩 읽는다. 5MB 파일도 수십 MB 안에서 처리한다. */
    private static Workbook open(InputStream in) {
        try {
            return StreamingReader.builder()
                    .rowCacheSize(100)
                    .bufferSize(4096)
                    .open(in);
        } catch (RuntimeException e) {
            throw invalid("not a valid .xlsx file", e);
        }
    }
```

```java
    private static ApiException invalid(String message, Throwable cause) {
        return new ApiException(ErrorCode.INVALID_FILE_FORMAT, message, cause);
    }
```

- [ ] **Step 6: 파싱을 트랜잭션 밖으로**

`apps/api/src/main/java/com/saladbowl/api/importer/ImportService.java`의 `importFile`과 생성자를 바꾼다(`org.springframework.transaction.PlatformTransactionManager`, `org.springframework.transaction.support.TransactionTemplate` import, `importFile`의 `@Transactional` 제거. `recent`의 `@Transactional(readOnly = true)`는 그대로).

```java
    private final BanksaladParser parser;
    private final MergeService mergeService;
    private final ImportBatchRepository batches;
    private final TransactionTemplate transaction;

    public ImportService(BanksaladParser parser, MergeService mergeService, ImportBatchRepository batches,
                         PlatformTransactionManager transactionManager) {
        this.parser = parser;
        this.mergeService = mergeService;
        this.batches = batches;
        this.transaction = new TransactionTemplate(transactionManager);
    }

    /**
     * 파일 하나를 하나의 트랜잭션으로 반영한다. 파싱은 DB 커넥션을 잡기 전에 끝낸다
     * (형식 오류면 아무것도 쓰지 않고, 풀러 연결을 파싱 시간 동안 붙잡지 않는다).
     */
    public ImportResult importFile(long ownerId, String fileName, InputStream in) {
        List<ParsedRow> rows = parser.parse(in);
        return transaction.execute(status -> {
            ImportBatch batch = batches.save(new ImportBatch(ownerId, fileName));
            MergeService.MergeCounts counts = mergeService.merge(ownerId, batch.getId(), rows);
            batch.record(rows.size(), counts.created(), counts.updated(), counts.unchanged());
            return new ImportResult(batch.getId(), rows.size(), counts.created(), counts.updated(), counts.unchanged());
        });
    }
```

```java
package com.saladbowl.api.auth;

import org.springframework.boot.context.properties.ConfigurationProperties;

import java.util.Set;

/**
 * refresh 토큰 쿠키 속성. 배포 구성(같은 출처 프록시 / 개인 도메인)에 따라 값만 바꾼다.
 * 브라우저가 보는 경로 기준이므로 Pages 프록시 구성에서는 /api/auth다.
 * 잘못된 조합(예: SameSite=None인데 Secure가 아님)은 브라우저가 쿠키를 버리므로 기동할 때 막는다.
 */
@ConfigurationProperties(prefix = "app.auth.refresh-cookie")
public record RefreshCookieProperties(String path, String sameSite, boolean secure) {

    private static final Set<String> SAME_SITE_VALUES = Set.of("Strict", "Lax", "None");

    public RefreshCookieProperties {
        if (path == null || !path.startsWith("/")) {
            throw new IllegalArgumentException("app.auth.refresh-cookie.path must start with /");
        }
        if (!SAME_SITE_VALUES.contains(sameSite)) {
            throw new IllegalArgumentException("app.auth.refresh-cookie.same-site must be Strict, Lax or None");
        }
        if ("None".equals(sameSite) && !secure) {
            throw new IllegalArgumentException("SameSite=None requires secure=true");
        }
    }
}
```

```bash
#!/usr/bin/env bash
# 배포된 Salad Bowl을 계정 없이 점검한다. 사용법: scripts/smoke.sh https://<Pages 주소>
# 콜드스타트(Render 깨우기)를 위해 health는 최대 3분까지 다시 시도한다.
set -uo pipefail

base=${1:?usage: scripts/smoke.sh https://<pages-host>}
base=${base%/}
failures=0

check() {
  local name=$1 ok=$2
  if [ "$ok" = 0 ]; then echo "PASS  $name"; else echo "FAIL  $name"; failures=$((failures + 1)); fi
}

headers_of() { curl -sS -D - -o /dev/null --max-time 30 "$@"; }
body_of() { curl -sS --max-time 30 "$@"; }

# 1) 정적 파일
headers_of "$base/" | grep -qi '^content-type: text/html'; check "index.html" $?
headers_of "$base/" | grep -qi '^x-content-type-options: nosniff'; check "security headers" $?
body_of "$base/manifest.webmanifest" | grep -q '"Salad Bowl"'; check "manifest" $?
headers_of "$base/sw.js" | grep -qi '^cache-control: no-cache'; check "sw.js no-cache" $?

# 2) API health (콜드스타트 대기)
health=1
for _ in $(seq 1 18); do
  if body_of "$base/api/actuator/health" | grep -q '"status":"UP"'; then health=0; break; fi
  sleep 10
done
check "api health UP" $health

# 3) 인증 없는 요청은 401 JSON(SPA HTML이 아님)
me=$(curl -sS -o /tmp/smoke-me.json -w '%{http_code} %{content_type}' --max-time 30 "$base/api/me")
case "$me" in 401\ application/json*) check "/api/me 401 json" 0 ;; *) echo "      got: $me"; check "/api/me 401 json" 1 ;; esac

# 4) Origin을 붙인 refresh도 CORS 403이 아니라 401 JSON(프록시가 Origin을 지운다)
refresh=$(curl -sS -o /tmp/smoke-refresh.json -w '%{http_code} %{content_type}' --max-time 30 \
  -X POST -H "Origin: $base" "$base/api/auth/refresh")
case "$refresh" in 401\ application/json*) check "refresh with Origin is 401 json" 0 ;; *) echo "      got: $refresh"; check "refresh with Origin is 401 json" 1 ;; esac

echo "failures: $failures"
[ "$failures" = 0 ]
```
