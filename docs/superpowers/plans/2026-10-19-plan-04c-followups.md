# Plan 04c 후속 과제

Plan 04c(그룹 화면·초대·PWA·Pages 프록시)의 Task별 리뷰, 최종 리뷰, 로컬 브라우저 확인에서 나왔지만 이후로 넘긴 항목이다. [04a](2026-10-19-plan-04a-followups.md)·[04b](2026-10-19-plan-04b-followups.md) 후속 과제 중 04c 몫은 이번에 처리했다(아래 "04c에서 처리한 것").

## 04c에서 처리한 것 (기록용)
- 04a: `.nvmrc`·`engines`, 프록시 HTML 5xx·SPA 200 응답 처리, 로그인 탭 패턴, 회원가입 부분 실패, 세션 복원 실패 화면, 화면 전환 포커스, inline style 제거, breakpoint 820px, 헤더 링크 40px, 테스트 보강(로그인 후 `next` 복귀, 세션 만료 시 캐시 비우기, 오프라인 그룹 로딩, 가입 오류 문구).
- 04b: 대화상자 포커스 복귀·Tab 가두기·업로드 중 닫기 막기, 그룹에서 빠졌을 때(404) 그룹 목록 새로 고침, 월 입력 호환(이전·다음 달 버튼), 범위 버튼 눌림 상태.
- 최종 리뷰에서 고친 것: **프록시가 브라우저 `Origin`을 API로 넘겨 Spring CORS가 모든 POST·PUT·DELETE를 403으로 막던 문제**(배포하면 로그인·세션 갱신이 깨졌다), 확인 단계 포커스, 가입 안내 live region, 초대 주소 칸 좁은 화면 넘침, 초대 수락 후 그룹 목록 즉시 갱신.

## Plan 05 (배포)에서 확인할 것
- **Pages Function 경로**: `functions/api/[[path]].ts`가 `/api`, `/api/`, `/api/x`를 모두 받는지, 5MB multipart 업로드가 그대로 전달되는지 실제 배포에서 확인한다.
- **정적 파일 우선순위**: `/sw.js`, `/registerSW.js`, `/manifest.webmanifest`, workbox 파일이 SPA 폴백보다 먼저 정적 파일로 나가는지 확인한다.
- **`API_ORIGIN`**: 경로 없는 origin만 넣는다(경로를 넣으면 지워진다). 잘못된 값이면 `new URL`이 try 밖에서 던져 Pages 기본 500이 나온다. try 안으로 옮기거나 시작 시 검증한다.
- **넘기는 헤더**: `origin`·`host`만 지우고 나머지(`cf-*`, `x-forwarded-*`)는 그대로 넘긴다. API가 나중에 Origin·CSRF 검사를 넣으면 다시 본다.
- 업로드 본문 읽기(`arrayBuffer`) 실패도 "API에 닿지 못함"(502)으로 보고된다. 필요하면 구분한다.

## 다음 기능 계획에서 다룰 것
- **관리자의 그룹 떠나기**: 관리자는 나갈 수도, 관리자를 넘길 수도 없다(API `ADMIN_CANNOT_LEAVE`). 화면에도 이유 안내가 없다. 관리자 위임 기능을 [잔여 작업](../../backlog.md)에 올린다.
- **로그아웃 직후 URL**: 로그아웃하면 `RequireAuth`가 먼저 리다이렉트해 `/login?next=%2Fdashboard`가 된다. 다른 계정으로 로그인하면 그 화면으로 간다. 로그아웃은 `next` 없이 `/login`으로 보낸다.
- **초대 수락 직후 포커스**: 합류 후 대시보드로 가면 첫 화면이라 포커스가 `<body>`에 남는다.
- **업로드 후 포커스**: 업로드 대화상자를 연 달력 칸이 업로드 뒤 "등록됨"(버튼 아님)으로 바뀌어 포커스가 `<body>`로 간다. 여는 요소가 사라졌으면 제목이나 `main`으로 돌려준다.
- **복수 대화상자**: Esc 하나로 열린 대화상자가 모두 닫힌다(지금은 하나뿐). `isComposing`(한글 입력 중 Esc) 처리, 숨김·`inert` 요소를 포커스 목록에서 빼기.
- **재시도 판단**: 초대 미리보기·세션 복원에서 408·429도 "끝난 오류"로 본다. 다시 시도할 수 있게 구분한다. 수락 중 끝난 오류(이미 멤버·만료·차단)면 합류 버튼을 숨기고 이동 링크를 보여준다.

## 나중에 (사소함)
- 정원 6명이 세 곳에 하드코딩되어 있다(`MemberList`, `InviteSection` 2곳). 상수로 모은다.
- 차단 해제 중에는 모든 행의 버튼이 비활성이 된다(행별로 바꿀 수 있다).
- `MonthPicker` 안내 예시가 "2026-10"으로 고정, `.field`가 거래 목록의 `.inlineField`와 중복, `shiftMonth`의 NaN 처리.
- 대시보드 `<meter>`에 값 설명(`aria-valuetext`)이 없다. 다시 불러오다 실패하면 이전 데이터와 오류가 함께 보인다.
- 서비스 워커 `autoUpdate`: 지금 등록 스크립트는 페이지를 새로 고치지 않는다. 업데이트 안내가 필요해지면 `prompt` 방식으로 바꾼다.
- `.nvmrc`가 22의 최신 버전을 따라간다. 재현성이 필요하면 정확한 버전으로 고정한다.

  - 관리자 도구 오류·클립보드 실패, 초대 수락 시점의 410·403·이미 멤버
