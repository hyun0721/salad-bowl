예정 경로는 아직 파일이 존재하지 않는다. 각 단계 완료 시 이 표에 실제 경로·커밋·검토 결과를 기록한다.
승인되지 않은 제안을 확정 요구사항으로 바꾸지 않는다. 필요한 결정은 근거와 추천안을 준비해 사용자에게 확인한다.
이 준비 요청만으로 다음 세 단계를 자동 실행하지 않는다.

## 이후 작업 공간

현재 준비 브랜치가 진행 중이면 해당 worktree에서 이어간다. 기본 체크아웃에서는 수정하지 않는다.
준비 브랜치가 병합되었다면 fetch 후 최신 origin/main에서 새 브랜치·worktree를 만든다.
아직 병합되지 않은 문서를 다른 브랜치로 넘길 때는 해당 문서 커밋을 명시적으로 가져와 누락을 막는다.
