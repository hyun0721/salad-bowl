# Plan 08 후속 과제

Plan 08(접근성 마무리와 운영 작은 수정)의 Task별 리뷰, 최종 리뷰에서 나왔지만 넘긴 항목과, 아직 남은 Plan 06 범위를 적는다.

## 실행 중 바뀐 결정 (기록용)
- **병렬 진행**: 서로 다른 파일을 바꾸는 Task(API Task 5와 웹 Task 1)를 동시에 구현하고, 앞 Task 리뷰와 다음 Task 구현을 겹쳐 돌렸다. 구현자는 같은 파일을 함께 건드리지 않았다.
- **동시 업로드 503**: 서버 대기 시간(20초)은 그대로 둔다. Cloudflare 프록시는 응답을 100초까지 기다리고 import 한 건이 약 81초라, 대기를 늘리면 프록시 한도에 걸린다. 오류 문구에 "1~2분 뒤"를 알렸다.
- **1MB 초과 요청**: Tomcat 기본 swallow 한도(2MB)까지는 서버가 이미 413을 낸다. 프록시가 본문을 읽은 뒤 1MiB를 넘으면 API를 부르지 않고 413 `FILE_TOO_LARGE`로 답한다.

## 실기기 확인 (사용자가 직접)
[Plan 07c 후속](2026-10-25-plan-07c-followups.md)의 실기기 목록과 함께 본다.
- 좁은 화면 그룹 만들기·월 데이터 삭제 시트: 바깥(어두운 배경)을 눌러도 닫히지 않고, 닫기·Esc·아래로 쓸기로는 닫히는지. 확인 대화상자(삭제·나가기·내보내기)는 바깥을 누르면 닫히는지.
- 좁은 화면에서 다른 달 거래를 수동 추가: 시트가 닫혔다 다시 열리지 않고 새 거래 상세로 바뀌는지.
- 좁은 화면 거래 상세·추가 전체 높이 시트: 바깥을 눌러도 닫히지 않고, 닫기·Esc·아래로 쓸기로는 닫히는지.
- 멤버 내보내기 뒤 포커스가 "멤버 (n/6)" 제목으로 가는지(스크린리더가 읽는지).
- 업로드 중 "서버를 깨우는 중" 안내가 뜨지 않는지(서버가 잠든 상태에서 업로드로 처음 깨울 때는 업로드 진행 표시만 보인다).
