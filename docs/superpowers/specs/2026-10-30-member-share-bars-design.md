# 대시보드 분포의 멤버별 구성 막대 설계

- 작성일: 2026-10-30
- 상태: 승인됨 (2026-10-30)
- 이어 받는 문서: [대시보드 2탭 설계](2026-10-30-dashboard-two-tabs-design.md)

## 1. 목표

대분류·소분류 분포에서 각 카테고리를 멤버별로 얼마만큼 썼는지 본다. 추이 카드는 멤버 수 × 카테고리 수만큼 선이 늘어 읽기 어려워 합산 그대로 둔다. 멤버 비교 메뉴는 따로 만들지 않는다.

## 2. API

`GET /groups/{groupId}/summary/members?month=yyyy-MM` → `[{ major, minor, userId, expense }]`

- 선별은 `summaryTransactions`(KRW, 이체·숨김 제외)와 같고 지출만 센다. 키는 `majorLabel`·`minorLabel`이다. 같은 월에서 `userId`를 합치면 `/summary/subcategories`의 그 월 행과 같다.
- 금액은 순지출(환불 차감)이라 음수일 수 있다.
- 정렬: major, minor, userId 오름차순.
- 공개 범위: 대상은 `access.sharedOwnerIds(groupId)`뿐이다. 멤버를 고르는 인자는 없으므로 범위 밖 userId를 넘길 경로가 없다. 공개를 끈 멤버와 그룹 밖 사용자의 거래는 응답에 나오지 않는다. 그룹 멤버가 아니면 다른 요약과 같이 404다. 월 형식·범위 오류는 400이다.

## 3. 화면

- 대분류 분포에 소분류 분포와 같은 보기 전환(차트 | 목록)을 단다.
- 두 분포의 목록 보기는 같은 막대 목록 부품을 쓴다. 행마다 굵게 강조한 카테고리 이름·오른쪽 정렬한 금액·비율, 멤버별 구간으로 나눈 막대, 막대 아래 멤버별 금액 줄을 보인다.
  - 막대 전체 길이 = 카테고리 순지출 ÷ 양수 총지출(지금 규칙). 그 길이를 멤버별 양수 금액 비율로 나눈다. 음수 멤버는 구간을 그리지 않고 금액 줄에 "환불 초과"로 적는다.
  - 멤버 색은 요약 `byMember` 순서의 차트 색(`--chart-1`부터)이다. 그룹은 최대 6명이라 실선 색으로 충분하다. 목록 위에 멤버 범례를 둔다. 멤버명은 범례에 한 번 표시하고, 각 행에는 같은 색 점과 금액만 보인다. 멤버명은 스크린리더용 텍스트와 hover title에도 남긴다.
  - 색만으로 구분하지 않는다. 막대는 `role="img"`와 멤버별 금액을 담은 `aria-label`을 갖고, 금액 줄을 항상 보인다(좁은 화면에서도 접지 않는다).
- 대분류 목록 행을 누르면 지금처럼 거래 창이 열린다. 소분류 목록 행은 누르는 동작이 없다.
- 멤버 데이터를 불러오지 못하면 막대를 지금처럼 한 색으로 그리고 멤버 줄을 생략한다(분포 자체는 막지 않는다).
