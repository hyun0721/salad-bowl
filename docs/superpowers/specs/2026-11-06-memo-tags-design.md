# 메모 태그 검색·일괄 태그

거래 메모의 `#태그`를 읽어 목록에서 찾고, 선택한 거래에 일괄로 붙이고 뗀다. 태그는 메모에서 읽어 내는 값이고 별도 저장소를 두지 않는다. 웹 수정 보호(override)의 메모 규칙을 한 가지 더한다.

## 태그 규칙

- 태그는 `#` 뒤 글자·숫자·`_` 1~50자다. `#` 앞은 문장 처음이거나 공백이어야 하고, 뒤는 문장 끝이거나 그 밖의 글자여야 한다. `a#b`와 51자 이상은 태그가 아니다.
- 정규식은 서버와 웹이 같다: `(?<!\S)#([\p{L}\p{N}_]{1,50})(?![\p{L}\p{N}_])`.
- 비교 전에 NFC로 맞추고 대소문자를 구분한다. 일괄 추가·제거와 태그 목록은 토큰 전체가 같을 때만 같은 태그다. 검색창만 부분 일치다.
- 추출·추가·제거는 서버 파서(`MemoTags`)를 기준으로 하고 웹은 같은 예시표로 맞춘다.

| 동작 | 입력 메모 | 태그 | 결과 |
|---|---|---|---|
| 추출 | `예식장 #결혼준비 계약금` | | `결혼준비` |
| 추출 | `a#b #ok, #한글_1` | | `ok`, `한글_1` |
| 추가 | (빈 메모) | `여행` | `#여행` |
| 추가 | `숙소` | `여행`, `제주` | `숙소 #여행 #제주` |
| 추가 | `숙소 #여행` | `여행`, `제주` | `숙소 #여행 #제주` |
| 제거 | `예식장 #결혼준비 계약금` | `결혼준비` | `예식장 계약금` |
| 제거 | `#여행 #제주` | `여행` | `#제주` |
| 제거 | `#여행` | `여행` | (빈 메모) |
| 제거 | `숙소` | `여행` | `숙소` (변경 없음) |

제거는 태그와 그 앞 공백 하나를 지운다. 문장 맨 앞이면 뒤 공백을 지운다. 줄바꿈 등 다른 공백은 건드리지 않는다.

## 일괄 편집 API

`PATCH /transactions/bulk`에 `addTags`, `removeTags`(각 최대 20개, 각 `#` 유무 무관)를 더한다. 태그 형식이 틀리면 400이다.

- 거래마다 현재 표시 메모(override가 있으면 override, 없으면 원본)에서 제거 뒤 추가를 적용한다. 결과가 같으면 건드리지 않는다.
- 결과 메모가 1000자를 넘는 거래가 하나라도 있으면 전체를 400으로 거절하고 몇 건인지 메시지에 넣는다.
- 감사 로그는 `memo` 항목으로 거래별로 남긴다.
- 웹 수정 보호 규칙: 결과가 빈 메모인데 원본 메모가 있으면 빈 문자열을 override로 저장한다(원본 태그가 되살아나지 않는다). 원본도 비어 있으면 override를 지운다. 결과가 원본과 같으면 override를 지운다. 단건 수정은 바뀌지 않는다. 메모를 비워 저장하면 원본으로 돌아간다.
- 카테고리는 대분류와 소분류를 함께 보내야 한다. 대분류는 비어 있지 않아야 하고 소분류는 빈 문자열(소분류 없음)을 허용한다. 소분류만 보내면 400이다. 일괄 수정에서는 빈 소분류를 빈 override로 저장한다.

## 태그 목록 API

`GET /me/tags`, `GET /groups/{groupId}/tags`가 `[{tag, count}]`를 많이 쓴 순, 같으면 이름순으로 최대 200개 돌려준다. 내 목록은 내 거래 전체(숨김 포함), 그룹 목록은 공개 중인 멤버의 숨기지 않은 거래다. 기간 제한이 없다. `count`는 그 태그가 붙은 거래 수다.

## 화면

- 검색창이 메모도 찾는다. `#결혼`은 `#결혼식`도 찾는다. 선택한 달 안에서만 찾는다.
- 표와 카드가 태그를 칩으로 보여 주고, 칩을 누르면 검색창에 `#태그`가 들어간다. 선택 모드에서는 칩이 선택을 바꾸지 않는다.
- 일괄 편집 창은 타입, 대분류·소분류(같은 행, 일반 Select), 숨기기, 태그 추가, 태그 제거 순서다.
  - 대분류를 고르면 소분류도 골라야 적용된다. 소분류는 대분류를 고르기 전까지 비활성이고 `소분류 없음`을 고를 수 있다.
  - 태그 추가는 `#`을 붙여 여러 개 입력하고, 전체 데이터의 태그를 후보 칩으로 제안한다.
  - 태그 제거는 선택한 거래에 실제로 붙은 태그만 건수와 함께 보여 준다.
  - 메모가 1000자를 넘는 거래가 있으면 보내기 전에 막고 건수를 알린다.

## 하지 않는 것

메모 입력 중 `#` 자동완성, 여러 달에 걸친 태그 검색(`from`/`to`)과 태그별 금액 합계, 태그 이름 변경, 별도 태그 저장소·인덱스. 합계는 태그 목록과 같은 범위의 거래를 읽어 정확 일치로 더하면 되고, 느려지면 `memo_tags text[]`와 GIN 인덱스를 둔다.
