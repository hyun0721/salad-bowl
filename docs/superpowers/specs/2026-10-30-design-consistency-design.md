# 화면 제목·추가 버튼·수입/지출 표기 통일 설계

- 작성일: 2026-10-30
- 상태: 승인됨 (2026-10-30)
- 기준: main `6af8e9d`(대분류 거래 창 PR #60 반영 뒤)

## 1. 목표

메뉴마다 다른 제목·추가 버튼·수입/지출 표기를 한 가지 규칙으로 맞춰, 화면을 옮겨도 같은 자리에서 같은 모양을 찾게 한다. 모바일 PWA(Android·iOS, ≤820px)와 넓은 화면 모두 적용한다.

## 2. 지금 상태 (2026-10-30, 375×812·데스크톱 캡처)

| 화면 | 제목 | 추가 버튼 | 수입/지출 |
|---|---|---|---|
| 홈 | `내 가계부` (메뉴 `홈`과 다름) | 없음 | `₩ 3,000,000`, 무채색, 누를 수 없음, 아래 `내 거래 보기` 링크 |
| 대시보드 | 숨김 h1 `그룹 대시보드` | 없음 | `3,000,000 (원)`, 수입 빨강·지출 파랑, 누르면 멤버별 창 |
| 거래 목록 | `거래 목록`, `ui.pageHeader` 안에서 44px 버튼과 한 줄이라 다른 화면보다 아래로 내려가 보인다 | 제목 오른쪽 `+ 추가` | — |
| 업로드 | `뱅크샐러드 엑셀 업로드` (메뉴 `업로드`와 다름) | 없음 | — |
| 그룹 | `그룹 관리` | 제목 아래 별도 줄 `+ 그룹 만들기`, 아이콘 18px | — |

- 대시보드 수입/지출 카드는 대분류·소분류 탭 **아래**에 같은 내용으로 반복된다. 월 선택은 대분류에만 있고 소분류는 `?month=`를 무시하고 지난달로 고정된다(`DashboardPage.tsx`의 `level === 'major' && isYearMonth(requested)`).
- PWA 안전 영역은 이미 처리되어 있다: 상단 `body` padding과 상태 바 띠(`base.css`), 본문 좌우 `safe-area-inset-left/right`, 하단 탭 바 + `safe-area-inset-bottom`. 이번 변경은 이 규칙 안에서만 그린다.

## 3. 범위

- 바꾸는 것: 다섯 주 화면의 제목 줄, 거래 목록·그룹 관리의 추가 버튼, 홈·대시보드의 수입/지출 카드, 대시보드 상단 순서와 월 적용 범위.
- 하지 않는 것: 업로드·그룹 화면 내부 카드 배치, 색·간격 토큰 값 변경, API 변경, 거래 목록 금액 색, 초대 화면(`/invite`, 메뉴 밖 화면) 제목.

## 4. 공통 제목 줄 `PageHeader`

새 파일 `apps/web/src/common/PageHeader.tsx` (+ `.module.css`).

```tsx
<PageHeader title="거래 목록" action={<button …>…</button>} />
```

- `title`: 보이는 `h1`. 다섯 화면 모두 이 부품으로 제목을 그린다.
- `action`(선택): 제목 오른쪽 끝에 붙는 노드. 없어도 줄 높이는 같다.
- 줄 높이는 `min-height: var(--control-height)`로 고정한다(좁은 화면 44px, 넓은 화면 32px 토큰을 그대로 따른다). 제목은 세로 가운데 정렬이라 버튼 유무와 관계없이 같은 자리에 놓인다.
- 제목이 길어도 버튼과 줄을 나누지 않는다: 제목 `min-width: 0` + 말줄임, 버튼 `flex: none`.
- `ui.pageHeader`는 `SubcategoryTrends` 카드 머리에서도 쓰이므로 지우지 않는다. 페이지 제목 줄은 모두 `PageHeader`로 옮긴다.

### 제목 문구

메뉴(`app/menu.ts`)의 `label`과 같게 한다. 탭 제목(`usePageTitle`)도 같은 값을 쓴다.

| 화면 | 보이는 제목 | 탭 제목 |
|---|---|---|
| 홈 | 홈 | 홈 |
| 대시보드 | 그룹 대시보드 | `그룹 대시보드 · 대분류`/`· 소분류` (지금 그대로) |
| 거래 목록 | 거래 목록 | 거래 목록 |
| 업로드 | 업로드 | 업로드 |
| 그룹 관리 | 그룹 관리 | 그룹 관리 |

- 화면에서 문자열을 다시 쓰지 않도록 각 화면은 `MENU`에서 label을 찾아 쓴다. 대시보드 탭 제목의 접두도 같은 값을 쓴다.
- 대시보드는 숨김 h1을 보이는 h1로 바꾼다. 그룹 로딩·오류·그룹 없음 상태에서도 같은 제목 줄을 그린다. 주 메뉴 이동 시 h1로 포커스를 옮기는 `FocusHeadingOnRouteChange`는 그대로 동작한다.

## 5. 추가 버튼

- 거래 목록과 그룹 관리 모두 `PageHeader`의 `action`에 같은 버튼을 둔다: `ui.button ui.primary`, `<Icon name="plus" />` 기본 크기, 보이는 글자 `추가`.
- 접근 이름: 거래 목록 `거래 추가`(지금 그대로), 그룹 관리 `그룹 추가`.
- 그룹 관리의 별도 버튼 줄(`.actions`)은 없앤다. 버튼이 여는 창 제목 `새 그룹 만들기`와 동작은 바꾸지 않는다.
- 그룹 관리의 빈 상태 문구 "위의 그룹 만들기로"는 "위의 추가 버튼으로"로 바꾼다. 대시보드 `NoGroupNotice`의 `그룹 만들기` 링크는 그룹 관리로 가는 안내 문구라 그대로 둔다.

## 6. 수입/지출 공용 카드 `TotalsCards`

새 파일 `apps/web/src/common/TotalsCards.tsx` (+ `.module.css`). 대시보드의 `.totals/.total*` 스타일을 옮겨 온다.

```tsx
<TotalsCards income={n} expense={n} onSelect={(kind) => …} />
```

- 두 장의 카드(수입·지출)를 한 줄에 그린다. `repeat(auto-fit, minmax(150px, 1fr))`로 아주 좁은 폭에서는 한 줄에 하나씩 둔다.
- 금액은 `formatWon`(`₩ 3,000,000`)으로 통일한다. `(원)` 단위 표기는 없앤다.
- 색: 수입 `--amount-income`, 지출 `--amount-expense`. 좁은 화면 금액 글자는 지금 대시보드의 `clamp(var(--text-md), 4vw, var(--text-lg))` + `nowrap`을 그대로 쓴다.
- 카드는 버튼이다. 접근 이름 `수입 ₩ 3,000,000`. 누르면 `onSelect('income' | 'expense')`. 호버·`focus-visible` 표시는 지금 대시보드 규칙을 쓴다. 창을 여는 화면만 `aria-haspopup="dialog"`가 필요하므로 `opensDialog`(선택, boolean)로 받는다.
  - 대시보드: `aria-haspopup="dialog"`, 누르면 지금처럼 `MemberTotalsDialog`를 연다.
  - 홈: 누르면 `/transactions`로 이동한다(`useNavigate`). 거래 목록의 기본 달은 홈과 같은 `defaultYearMonth`(지난달)라 같은 달을 보여준다. 홈 요약 카드의 `내 거래 보기` 링크는 없앤다.

## 7. 대시보드 순서와 월

```
PageHeader 그룹 대시보드
MonthPicker                 ← 두 탭 공통
TotalsCards                 ← 두 탭 공통, 탭을 바꿔도 다시 그리지 않음
DashboardMenu [대분류|소분류] (좁은 화면만, 넓은 화면은 사이드바 하위 메뉴)
탭 내용 (대분류: 카테고리별 지출·대분류별 추이 / 소분류: SubcategoryTrends)
```

- 월은 두 탭 모두 `?month=`를 따른다. 값이 없거나 잘못되면 지난달이다. 소분류 카드는 이미 `month` prop을 받으므로 고른 달까지 최근 6개월을 보여준다.
- 대분류 거래 창의 `… 소분류 보기`가 넘기는 `?month=`가 이제 소분류에도 적용된다(2탭 설계 4장과 맞는다).
- 탭 이동(replace)과 사이드바 하위 링크는 지금처럼 `search`를 유지하므로 달이 이어진다.
- 동작 변화: 소분류 북마크·링크에 `?month=`가 있으면 그 달 기준이 된다(지금은 무시하고 지난달).

## 8. 모바일 PWA

- 새 부품은 본문(`AppLayout .content`) 안에만 놓여 기존 좌우·하단 안전 영역 여백을 그대로 받는다. 고정 위치 요소를 새로 만들지 않는다.
- 터치 대상: 추가 버튼과 카드 모두 좁은 화면에서 높이 44px 이상(`--control-height`, `ui.button` 규칙).
- 거래 목록은 화면 높이 맞춤(`data-fit-viewport`) 구조라 제목 줄이 `flex: none`으로 남아야 한다. `PageHeader`는 높이가 고정이므로 목록 높이 계산이 바뀌지 않는다.
