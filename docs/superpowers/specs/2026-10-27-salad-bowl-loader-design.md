# 샐러드볼 로딩 모션 설계

- 작성일: 2026-10-27
- 상태: 승인됨 (2026-10-27, 사용자가 "시작 화면 + 앱 안 느린 요청", "시간에 따라 차오름", "반투명 배경 + 조작 막기"를 고르고 설계를 승인함)

## 1. 목표

서버가 잠들어 있으면(Render 콜드스타트, 최대 4분) 지금은 글자 안내만 보인다.
- 앱 시작 화면: "불러오는 중입니다."
- 3초 넘는 요청: 위쪽의 "서버를 깨우는 중" 배너

이를 화면 가운데의 샐러드볼 모션으로 바꾼다. 재료가 하나씩 볼에 담기는 모습이 스피너이자 진행 표시 역할을 한다. 멘트는 딱딱하지 않게 단계별로 넘어간다.

## 2. 컴포넌트 `common/SaladBowlLoader.tsx`

- **그림**
  - 인라인 SVG이고 `aria-hidden`이다.
  - `public/logo.svg`의 도형을 그대로 쓴다: 흰 볼, 잎 3장, 토마토. 여기에 드레싱 줄기를 더한다.
  - 배경 사각형은 쓰지 않는다. 색은 로고와 같은 값이다.
  - 볼은 테두리(`--line`)를 둘러 밝은 테마에서도 보이게 한다.
- **단계**: 표시된 뒤 흐른 시간으로 정한다.

| 단계 | 시작 | 담기는 것 | 멘트 |
|---|---|---|---|
| 1 | 0초 | 잎 1 | 신선한 재료 찾는 중이에요 |
| 2 | 8초 | 잎 2, 볼이 한 번 흔들림 | 맛있게 섞는 중이에요 |
| 3 | 30초 | 토마토, 드레싱 줄기 | 드레싱 넣는 중이에요 |
| 4 | 90초 | 잎 3, 볼이 천천히 계속 흔들림 | 거의 다 됐어요, 조금만요 |

- **재료 모션**
  - 재료는 위에서 떨어져 볼에 담긴다(약 600ms, 살짝 튕김).
  - 이미 담긴 재료는 그대로 둔다. 차오름이 진행을 뜻한다.
- **멘트**
  - `role="status"`인 문단에 둔다. 단계가 바뀌면 글자만 바뀌어 스크린리더가 읽는다.
- **보조 문구** (`slow` prop이 참일 때만)
  - 멘트 아래에 "오래 쓰지 않았다면 서버가 깨어나는 데 최대 4분쯤 걸려요"를 작게 보인다.
- **완료**
  - `done` prop이 참이 되면 남은 재료를 짧은 간격(합계 약 400ms)으로 마저 담는다.
  - 다 담으면 `onFinished`를 부른다.
- **움직임 줄이기** (`prefers-reduced-motion: reduce`)
  - 떨어짐·흔들림 없이 재료가 페이드(150ms)로 나타난다.
  - 멘트와 단계 시점은 같다. 완료할 때는 곧바로 `onFinished`를 부른다.
- **구현**
  - 단계는 `setTimeout`으로 정한다.
  - 모션은 CSS Modules keyframes로 만든다. 새 의존성은 없다.

## 3. 앱 시작 화면

- `RequireAuth`·`PublicOnly`에서 `status === 'loading'`이면 `<p className={styles.loading}>불러오는 중입니다.</p>` 대신 화면 가운데에 `SaladBowlLoader`를 둔다.
  - `slow` prop은 `isSlow` 구독 값이다.
- 시작 화면에서는 복원이 끝나면 곧바로 다음 화면으로 넘어간다. 완료 모션은 쓰지 않는다. 화면 전환을 늦추지 않으려는 것이다.
- 시작 화면이 로딩 중이면 4장의 덮개를 띄우지 않는다. 볼이 두 개 겹치지 않게 하려는 것이다.

## 4. 앱 안·로그인 요청: `app/SlowServerOverlay.tsx`

- 지금의 `SlowServerNotice`를 이 컴포넌트로 바꾼다. 쓰는 곳은 `AppLayout`, `PublicOnly`(로그인 화면), `RequireAuth`(unavailable일 때)다.
- `isSlow`가 참이 되면 RAC `ModalOverlay` + `Modal` + `Dialog`(`aria-label="서버 준비 중"`)를 연다.
  - 바깥 클릭과 Esc로 닫히지 않는다.
  - 포커스는 RAC가 가두고, 닫히면 돌려준다.
  - 반투명 배경(`--overlay`)이 조작을 막는다.
  - 가운데 카드(`--surface-000`, 둥근 모서리)에 `SaladBowlLoader slow`를 넣는다.
- z-index는 25다. 모달(10)·시트(20)보다 위, 토스트(30)보다 아래다.
- `isSlow`가 거짓이 되면 `done`을 넘긴다. `onFinished` 뒤에 닫는다.
  - 완료 모션 중에 다시 느려지면 처음부터 다시 시작하지 않는다. 그대로 열린 채 단계를 이어 간다.
- 화면 읽기 프로그램용 기존 안내 문구는 덮개 안의 멘트·보조 문구가 대신한다.

## 5. 테스트

- **`SaladBowlLoader`** (가짜 타이머)
  - 0·8·30·90초에 멘트와 담긴 재료 수가 바뀐다.
  - `slow`일 때만 보조 문구가 보인다.
  - `done`이면 `onFinished`가 불린다.
  - 움직임 줄이기면 곧바로 불린다.
- **`SlowServerOverlay`**
  - 느린 요청이 없으면 대화상자가 없다.
  - 마운트 때 이미 느리면 바로 연다.
  - 요청이 끝나면 닫힌다.
- **`RequireAuth`·`PublicOnly`**
  - loading이면 로더 멘트가 보이고 덮개 대화상자가 없다.
- **화면 확인**: Playwright로 데스크톱·모바일에서 단계별 스크린샷을 찍는다(밝은·어두운 테마).

## 6. 범위 밖

- 실제 서버 준비 정도를 받아 오는 진행률(서버가 알려 주지 않는다)
